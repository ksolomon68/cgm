Setup — Resend
1. Upload send-email.php to the same server as this portal — it holds the Resend API key server-side, which keeps it out of the browser
2. Set the Endpoint URL below to wherever that file lives (e.g. /send-email.php)
3. Paste the Shared Secret you set inside send-email.php (the PORTAL_SECRET constant)
4. Click Save, then send yourself a test email
